## Módulos

| Módulo        | Versión    | Descripción                                  |
| ------------- | ---------- | -------------------------------------------- |

| [`raa`](raa/) | 19.0.1.0.2 | Sistema de Registro de Actos Administrativos |

## Instalación

Dependencias: [`odoo-tmc`](https://github.com/tmcrosario/odoo-tmc), [`odoo-tmc-data`](https://github.com/tmcrosario/odoo-tmc-data) (privado).

Agregar a la ruta de addons, actualizar aplicaciones e instalar «TMC ME» y «TMC RAA».
